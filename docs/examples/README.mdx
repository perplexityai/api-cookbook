# Examples Overview

Welcome to the **Perplexity Sonar API Examples** collection! These are production-ready applications that demonstrate real-world use cases of the Sonar API.

## 🚀 Quick Start

Navigate to any example directory and follow the instructions in the README.md file.

## 📋 Available Examples

### 👤 [Customer Enrichment with ClickHouse](customer-enrichment-agent-api/)

**Purpose**: Enrich customer records with validated public professional evidence

**Type**: Python command-line tutorial

**Use Cases**: CRM enrichment, identity disambiguation, source-backed data pipelines

**Key Features**:
- Uses the Agent API's built-in `people_search` tool with two custom functions
- Reads source records and appends provenance to local ClickHouse
- Validates every model-selected result ID against structured tool output
- Includes deterministic fixtures and an opt-in live smoke test

**Quick Start**:
```bash
cd customer-enrichment-agent-api/
uv sync --frozen
docker compose up -d
```

## 🔑 API Key Setup

All examples require a Perplexity API key. You can set it up in several ways:

### Environment Variable (Recommended)
```bash
export PPLX_API_KEY="your-api-key-here"
```

### .env File
Create a `.env` file in the example directory:
```bash
PERPLEXITY_API_KEY=your-api-key-here
```

### Command Line Argument
```bash
python script.py --api-key your-api-key-here
```

## 🛠️ Common Requirements

All examples require:
- **Python 3.7+**
- **Perplexity API Key** ([Get one here](https://docs.perplexity.ai/guides/getting-started))
- **Internet connection** for API calls

Additional requirements vary by example and are listed in each `requirements.txt` file.
