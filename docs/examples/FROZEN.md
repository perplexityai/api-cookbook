# Frozen

This directory is frozen for new contributions. It contains both legacy Sonar material and examples that already use the Agent API. The examples are no longer maintained here; check each one's API and dependencies before running it.

Current, tested Agent API examples live in the [cookbook on docs.perplexity.ai](https://docs.perplexity.ai/docs/cookbook). This repository accepts community showcase projects only; see [CONTRIBUTING.md](../../CONTRIBUTING.md).
